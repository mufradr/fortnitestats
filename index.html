A LITTLE BRIEFING

Go beyond the obvious.

Answer seven prompts, with 25 seconds for each. Enter one valid answer per prompt. Less obvious answers in our curated list earn more points.

  1. The clock starts when each prompt appears.
  2. Wrong answers don’t end the round. Try again until time runs out.
  3. A valid answer locks in your score. Every point takes you 10 metres deeper.
  4. Your first daily run is saved on this browser. Replay in practice after finishing.

Everyone gets the same seven prompts each UTC day. Scores are author-assigned tiers, not live popularity measurements. This is an independent game with original questions and artwork, not an official Krillion client.
